# Words on ZTR3AM — Leaderboard

Site estático oficial da leaderboard, publicado por GitHub Pages.

- O login usa OAuth da Twitch com um cliente público.
- O token de sessão existe apenas no `sessionStorage` do navegador.
- O motor local publica `leaderboard.json` ao arrancar e no final de cada partida.
- Tokens GitHub nunca fazem parte deste repositório.
